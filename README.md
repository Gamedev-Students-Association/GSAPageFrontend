# GSA Frontend

## opis

W tym repozytorium znajduje się kod strony koła GSA. Napisany jest on przy użyciu frameworku vue.

## Instrukcje

Po pobraniu należy użyć komend:

dla node.js:

'''sh
npm install
'''

dla deno:

'''sh
deno install
'''

Aby uruchomić serwer do testowania naluży użyć:

dla node.js:

'''sh
npm run dev
'''

dla deno:

'''sh
deno task dev
'''
