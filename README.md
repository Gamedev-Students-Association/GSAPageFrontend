# GSA Frontend

## Opis

Tu znajduje się kod nowej strony koła.

## Instrukcje

Po pobraniu należy użyć komend:

dla node.js:

```powershell
npm install
```

dla deno:

```powershell
deno install
```

Aby uruchomić serwer do testowania naluży użyć:

dla node.js:

```powershell
npm run dev
```

dla deno:

```powershell
deno task dev
```
